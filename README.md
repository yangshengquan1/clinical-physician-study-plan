# 临床执业医师 30 天刷题打卡应用

## 使用

1. 双击 `index.html`，即可使用计划、打卡、错题、套卷、统计、备份和导入功能。
2. 需要尝试 AI 重排时，运行 `start.bat`（需要本机 Node.js），浏览器会打开 `http://127.0.0.1:8080`。
3. 直接使用“Codex 重排”即可获得本地智能重排，无需 API 密钥。在线 AI 重排为可选功能：仅在服务端明确支持浏览器跨域请求时，才在“设置”填写 Responses API 端点、模型和密钥；密钥不会写入备份文件。

## 数据与迁移

- 所有学习数据保存在当前浏览器 localStorage，清理浏览器数据会一并清除。
- 使用右上角“备份”导出 JSON；新设备打开应用后在“设置”导入即可恢复。
- 不包含题干、答案或任何题库内容，仅保存任务、题量、错题数、小节和统计。

## AI 重排

- 本地智能重排会按次日、当前轮次或全部后续日期，优先安排必做任务、错题较多的系统和状态描述中点名的系统，并自动保存可回退版本。
- 配置在线 AI 后，应用会优先尝试在线重排；服务被跨域、网络或鉴权阻断时，会自动切回本地智能重排，不会丢失学习数据。
- 当前 Codex 的本地认证不会被网页读取；在线 AI 必须在本应用中自行填写可跨域服务的密钥。

## 浏览器提醒

应用内通知在页面打开时有效。每日 09:00 和 21:30 的独立提醒由 Codex 自动化创建，不依赖网页保持打开。

## 手机独立使用

- `http://127.0.0.1:8080` 不能发送给手机，也不能在电脑关闭后访问。
- 把应用发布到一个 `https://` 静态网站后，手机可以添加到主屏幕并离线打开最近缓存的页面。
- 手机上的“添加手机提醒”会下载日历文件；导入手机日历后，提醒由手机系统执行，不依赖电脑或浏览器运行。

具体发布、迁移和提醒导入步骤见 `手机发布与提醒.md`。
